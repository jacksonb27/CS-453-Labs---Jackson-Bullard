Purpose of Software: This software is an exercise in creating an Express route / OpenAPI documented task tracker. There are tasks defined in a file,
                     as well as instructions for executing said tasks. Tasks can be updated, added, deleted, or editted. Errors are accounted for and 
                     all requests and responses are logged using a logging function. 
            
------------------------------------------------------------------------------------

1. Requirements
    a. Node.js
    b. npm


2. Setup
    a. "npm install" in terminal window


3. Running
    a. "npm start" in terminal window
                Note: the server should start on //localhost:3000


4. API Functions
    a. GET /health
    b. GET /api/tasks
    c. GET /api/tasks/:id
    d. POST /api/tasks
    e. PUT /api/tasks/:id
    f. PATCH /api/tasks/:id
    g. DELETE /api/tasks/:id
